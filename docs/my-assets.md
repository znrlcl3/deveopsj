# 내 자산 1차

현재 UI는 엑셀·직접 입력을 중심으로 구성한다. 나무 API 연결 탭·진입 버튼은 숨겼으며 기존 연결정보와 `/broker/namuh` 기능은 유지한다. 보유분 직접 입력 화면의 엑셀 버튼은 현재 잔고 파일이 아닌 종합거래내역 가져오기로 이동한다.

- `/assets`: 기존 증권 보유분을 플랜별로 조회하며 계좌별 요약, 직접 보유분 입력, 수익률 상세로 이동한다.
- 예금·적금·현금/입출금통장은 원화 잔액과 기준일을 직접 등록·수정·삭제한다. 수정은 잔액 교체이며 거래 생성이 아니다.
- 잔액 조회·수정·삭제는 인증 회원 ID로 제한한다. 버전 검증으로 오래된 수정/삭제를 차단한다.
- 증권 평가액은 조회 가능한 종목만 포함하며 예수금은 포함하지 않는다. 수동 잔액과 투자 자산을 중복 등록하지 않는다.
- 직접 등록한 미연결 자산 잔액은 납입·현금흐름·목표 계산에 자동 반영하지 않는다. 목표는 누적 납입 원금과 연결 플랜 평가액을 별도로 표시한다.
- 기존 납입 메뉴는 내 자산 하단 안내에서 접근한다. 기존 기록과 URL은 보존한다.
- 실제 증권 계좌 식별/연동 방식 저장은 후속 작업이다. 거래내역 엑셀은 `/trades/import`에서 가져온다. 기존 보유분의 플랜을 임의로 계좌로 변환하지 않는다.

## 적용

운영 `ddl-auto=validate`에서는 `deploy/sql/20261105_add_asset_balance.sql`을 먼저 적용해야 한다. 이 변경에서 운영 SQL은 실행하지 않는다. 기존 데이터는 마이그레이션하거나 삭제하지 않는다.

## 계좌별 요약

- 상단에 계좌별 주식·ETF 현재 평가액과 전체 합계를 표시한다. 예수금·현금·예적금은 제외하며 선택한 월의 월말 잔액이 아니다. 평가 불가 계좌가 있으면 전체 합계도 숨기고, 조회 가능한 계좌 금액은 유지한다. 계좌명은 아래 상세 카드로 연결한다.
- `/assets/accounts`에서 조회 월을 선택한다. 현재는 실제 증권 계좌번호가 아닌 인증 회원 소유 자산 플랜 ID를 계좌 단위로 사용한다.
- 선택한 월에 거래·연결 수입이 있거나 현재 보유분이 있는 플랜을 표시한다. 평가 전체 실패 시 보유 여부를 알 수 없어 소유 플랜 전체를 표시한다.
- 매수 출금액·매도 입금액은 원화 정산금액이다. SNAPSHOT은 제외하고 historyOnly 매매는 포함한다.
- 배당·분배금과 이자는 Income의 세후 amount이며 sourcePlanId로 연결한다. 연결 없는 수입 또는 삭제된 플랜의 수입은 계좌 미연결 합계로 안내한다. 수수료·세금은 정산액에 이미 반영된 참고 금액이므로 다시 차감하지 않는다.
- 월별 실적과 현재 보유분 평가를 분리한다. 현재 수익률은 `(평가금액 - 남은 매입원금) / 남은 매입원금 × 100`, 소수 둘째 자리 HALF_UP이며 배당·이자·실현손익은 포함하지 않는다. 원금 0은 수익률을 표시하지 않는다.
- 일부 종목 시세가 없으면 해당 계좌 전체의 평가금액·손익·수익률을 숨긴다. 이전 시세·환율 및 거래 환율 대체는 안내한다. 평가 호출 실패에도 월별 내역은 유지한다.
- 추가 스키마 변경이나 데이터 이관은 없다. 새 컨트롤러 적용에는 애플리케이션 재시작이 필요하다.

## 목표 진행률의 두 기준

- 원금 기준은 기존 누적 납입액을 유지한다. 증권 매수대금이나 SNAPSHOT 원금을 별도로 더하지 않는다. 월평균 필요 납입액과 기존 상태 표시는 이 기준이다.
- 자산평가액 기준은 인증 회원의 목표에 연결된 본인 플랜만 집계한다. 보유수량을 반영하는 증권 거래 기록이 있으면 현재 포트폴리오 평가를 사용하고, 같은 플랜의 수동 평가액은 더하지 않는다. 전량 매도하여 보유분이 없으면 증권 평가액은 0이다.
- 증권 보유 기록이 없는 플랜은 오늘까지의 최신 수동 평가액을 사용한다. 미래 평가일은 제외한다. 플랜마다 한 건만 반영하며 기록의 기준일을 표시한다.
- 평가 자료가 없는 플랜이나 시세 누락이 있으면 일부 확인 금액만 표시하고 전체 달성률·남은 금액은 표시하지 않는다. 연결 플랜이 없는 상태도 0%로 단정하지 않는다.
- 미연결 예·적금·현금 잔액, 목표 직접 추가 납입은 평가액에 별도로 가산하지 않는다. 같은 돈의 이중 집계를 피하려면 해당 자산의 현재 금액을 연결 플랜의 수동 평가로 기록한다.
- 진행 막대는 100%까지만 표시하며 목표 상태를 자동 변경하지 않는다. 스키마 변경이나 기존 데이터 변경은 없다.
