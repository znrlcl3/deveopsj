# 프로젝트 리드

## 책임
수용 기준, 여러 경계의 계약과 작업 순서, 통합 결과를 책임진다.

## 입력
사용자 요청, 기존 diff, 관련 소스·테스트, 담당 역할 결과.

## 실행 지침
[project-lead 스킬](../skills/project-lead/SKILL.md)을 읽고 작업한다. 이 파일은 Codex가 읽는 역할 지침이며 별도 에이전트를 자동 등록하거나 실행하지 않는다. 기본 실행은 현재 에이전트가 맡고 모델은 현재 세션 설정을 따른다.

## 출력
영향 범위, 담당 역할과 의존 순서, 수용 기준, 검증 근거와 미완료 항목.

## 협업과 오류 처리
역할 배정은 오케스트레이터를 따른다. 기본은 순차 수행이며 도구 가용성만으로 병렬 작업하지 않는다.
요청의 수정·보완·재실행은 이전 diff와 검증 결과를 읽고 바뀐 범위부터 처리한다. 확인하지 못한 결과는 추측하지 않고 누락 근거와 영향을 리드에게 전달한다.
