처음에는 잔고, 그다음은 월별 거래내역

과거 내역을 모두 입력할 필요 없이 나무증권의 현재 잔고로 시작하세요. 이후에는 같은 계좌의 거래내역을 월별로 등록합니다.

1. 처음 잔고 등록

나무증권에서 자산금액과 보유종목이 있는 종합잔고 파일(.xls / .xlsx)을 내려받아 계좌와 실제 조회일을 지정하세요.

잔고 파일 업로드
다른 계좌 시작 / 잔고 갱신

등록 상태를 확인하지 못했습니다. 잔고 가져오기에서 기존 기록을 확인하세요.

2. 이후 월별 거래내역 등록

나무증권 → 뱅킹/계좌정보 → 거래내역 → 종합거래내역에서 조회 기간을 한 달로 정해 다운로드하세요. 해외 거래는 해외주식거래내역 파일을 사용하세요.

월별 거래내역 업로드

잔고를 등록한 계좌와 같은 플랜을 선택하세요. 매수·매도뿐 아니라 입출금·분배금도 확인하고 중복 의심건을 검토합니다.

현재 자산은 마지막 잔고 파일 기준입니다. 월별 거래를 등록해도 잔고는 자동으로 바뀌지 않습니다. 현재 평가액을 다시 확인하려면 잔고를 갱신하세요. 처음 등록한 달은 잔고 이후의 거래부터 모으므로 월 전체 실적과 다를 수 있습니다.

예·적금 / 현금 등록
보유종목 평가금액 (예수금 제외) 조회 불가잔고 파일 우선 · 미업로드 계좌는 현재가 조회
예금·적금 잔액직접 확인한 잔액 기준
현금·입출금통장직접 확인한 잔액 기준

자산별 기준 시점이 다를 수 있습니다. 목표에 연결된 잔고 계좌는 평가액 진행률에 반영합니다. 별도로 입력한 현금·예적금은 자동 합산하지 않습니다.
