파일을 확인하고 저장할 매수·매도, 계좌 입출금과 분배금·이자 수입을 선택하세요.

업로드하면 파일 원본 전체를 본인 계정·플랜에 보관합니다. 지원하지 않는 행과 환전 내역도 원본에 남습니다. 금융 합계는 선택 저장한 내역만 반영합니다. 같은 내용의 파일은 플랜별 한 번만 보관합니다.

등록한 분배금·이자는 수입 내역에서 확인하세요.

1. 나무증권에서 파일 다운로드

나무증권 → 뱅킹/계좌정보 → 거래내역 → 종합거래내역

같은 직투계좌 플랜에 두 파일을 나눠 가져오세요. 종합거래내역(간략)은 국내 매매·원화 입출금·분배금·이자를 등록하고 해외 매매는 제외합니다. 해외주식거래내역은 두 줄 머리글과 거래당 두 행을 포함한 원본 XLS/XLSX를 사용하세요. 화면에서 복사한 탭 구분 TXT도 지원합니다. 미국 USD 매매·소수점 매매를 지원하며 USD 배당·이자·외화 이체입출금은 계좌별 요약에 별도로 저장하고 환전은 제외합니다. 5MB / 2,000건까지 가능합니다.

2. 계좌에 해당하는 플랜과 파일 선택

중복 확인은 플랜별로 진행합니다. 같은 계좌의 파일은 항상 같은 플랜으로 가져오세요.

플랜을 먼저 등록해 주세요.

3. 거래·수입 확인 후 선택 저장

분배금은 배당·분배금, 예탁금 이용료는 이자 수입으로 등록합니다. 정산금액(실제 입금액)을 수입에 반영하며 계좌 잔액·보유수량은 변경하지 않습니다.

·

선택한 종목에 보유분 기준 기록이 있고 거래일이 그 기준일 이전 또는 같은 날이면 내역만 저장합니다. 월별 매매에는 포함하지만 보유수량·월말 보유원금에는 다시 더하지 않습니다.

그 외에는 보유수량에 반영합니다. 이전 매수가 빠져 매도 수량이 부족하면 전체 저장을 중단합니다. 실거래일 기준이며 같은 날 가져오는 거래는 매수 후 매도 순으로 처리합니다. 당일 거래 시각·실현손익 재현은 지원하지 않습니다.

저장 대상이 하나이고 중복이 없는 매매·입출금·분배금·이자는 자동 선택됩니다. 제외하려면 ‘저장 안 함’으로 변경하세요. 종목 후보가 여럿이거나 해외 ISIN이 처음이면 직접 연결하세요. 빨간 중복 의심 행은 실제 별도 거래인지 확인 체크한 뒤 추가 등록할 수 있습니다. 날짜·금액 오류 행은 저장할 수 없습니다. 저장 버튼을 누르기 전에는 등록되지 않습니다. 종합 양식은 종목명으로 후보를 찾고 해외 상세 양식은 ISIN 연결을 사용합니다. 종목명·시장·코드를 확인하세요. 확인 체크는 해당 행을 기존 기록에 추가한다는 뜻입니다. 같은 파일을 다시 올려도 기존 저장 건수로 중복을 다시 확인합니다. 미리보기는 10분 동안 유효합니다.

해외 매매는 해외주식거래내역 파일에서만 저장합니다. 외화 거래·정산액과 비용을 자동으로 읽습니다. 저장된 ISIN 연결과 종목명으로 자동 연결합니다. 한 종목으로 확정되지 않을 때만 후보를 선택하세요. 저장한 연결은 다음 업로드에 재사용합니다. 매수 환율은 입력하지 않으며 현재 평가액은 최신 환율로 계산합니다. 파일 환율은 자동 보존하며 환율 포함 손익을 거래내역 환율 기준으로 보여줍니다. IRP 계약 행은 제외하고 이체입금만 한 번 기록하세요.
