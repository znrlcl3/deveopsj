지출 엑셀 업로드
조회 월 엑셀 다운로드 파일과 같은 형식을 사용합니다.
필수 열: 날짜, 카테고리, 금액(원), 메모
XLSX만 가능하며 최대 5MB, 1,000건까지 등록됩니다.
한 행이라도 잘못되면 전체 등록이 취소됩니다. 고정지출 열은 참고용이며 업로드 내역은 일반 지출로 등록됩니다. 날짜·금액·메모가 같은 내역은 중복 후보로 표시하며, 미리보기에서 등록할 행을 선택합니다.
카드사 엑셀 가져오기
이용내역 파일 다운로드 방법
  • 신한카드: 마이 → 카드이용내역 → 엑셀 저장
  • 삼성카드: 이용내역 → 다운로드
삼성카드는 일시불+할부 이용내역을 다운로드해 주세요. 내려받은 XLSX 파일을 아래에서 선택하면 됩니다.
입력한 비밀번호는 파일을 여는 데만 사용하며 저장하지 않습니다.
삼성카드 기본 양식: 일시불+할부_카드이용내역조회.xlsx. 일시불은 승인일 기준으로 가져오고, 할부는 총액을 개월 수로 나눈 예상 원금을 확인한 뒤 월별 예정 지출로 만듭니다. 수수료·할인은 미포함입니다. 취소 거래는 등록하지 않습니다.
실제 할부 청구액을 가져올 때는 기존 청구명세서의 원금과 이자/수수료를 합쳐 청구월 1일의 지출로 등록합니다. 이미 할부 예정을 만든 거래와 중복되지 않게 확인해 주세요.
현재 신한카드, 삼성카드, 카카오뱅크 XLSX 양식을 지원합니다.
양식이 일치하지 않으면 저장하지 않고 오류를 표시합니다. 저장 전 미리보기에서 카테고리를 지정할 수 있습니다.
