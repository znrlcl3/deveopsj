  1. 나무 PLUG에 로그인하세요.
    나무 공식 이용 안내 열기에서 API 사용신청으로 이동합니다. 나무 계좌가 필요합니다.
  2. 약관과 유의사항을 확인하고 API 사용을 신청하세요.
    본인 계좌에 연결된 APPKEY와 APP Secret을 발급받습니다. 여러 계좌가 있어도 고객번호당 키 하나를 사용합니다.
  3. 아래 입력란에 키 두 개를 등록하세요.
    로그인 비밀번호·계좌 비밀번호·공동인증서는 입력하지 않습니다. 키는 채팅이나 게시글로 보내지 말고 이 연결 화면에서만 등록하세요.
  4. 계좌 목록을 불러오고 조회할 계좌를 선택하세요.
    본인 일반 계좌만 표시합니다. 모의투자·주문대리인 계좌는 이 화면에서 지원하지 않습니다.
  5. 보유잔고를 조회하고 확인 후 반영하세요.
    국내 또는 해외 시장을 선택합니다. 종목·수량·평균 매수가를 확인하고 계좌에 해당하는 플랜에 선택 반영합니다. 계좌마다 별도 플랜을 사용하는 것을 권장합니다.
  6. 월별 매매는 조회 월을 선택하세요.
    나무의 종합거래내역 중 매매 내역을 보여줍니다. 조회일자와 실제 거래일자가 다를 수 있습니다. 조회 결과는 앱의 매매 장부에 자동 저장되지 않습니다.

키와 토큰은 사용자별로 암호화해 보관합니다. 이 앱은 계좌 조회만 호출하며 주문·출금 기능을 제공하지 않습니다. API 키 자체의 권한을 조회 전용으로 바꾸는 기능은 아닙니다.

3. 보유분 확인 후 저장

이 시장의 보유종목이 없습니다. 기존 보유분은 변경하지 않았습니다.
